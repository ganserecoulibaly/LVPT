# Pages légales LVPT

Les informations personnelles de l'éditeur sont volontairement laissées sous forme de placeholders en MAJUSCULES.

À remplacer avant mise en production :

- `NOM PRÉNOM`
- `ADRESSE`
- `CODE POSTAL VILLE`
- `PAYS`
- `EMAIL`
- `TÉLÉPHONE`
- `SIREN`
- `SIRET`
- `RNE`
- `RCS — VILLE, SI APPLICABLE`
- `NUMÉRO TVA INTRACOMMUNAUTAIRE, SI APPLICABLE`

`CAPITAL SOCIAL` n'est pas demandé : LVPT est exploité sous le statut d'entrepreneur individuel.

Avant la mise en production commerciale, vérifier notamment :

1. les informations exactes d'immatriculation ;
2. le régime de TVA applicable ;
3. les informations d'hébergement et de sous-traitance réellement utilisées ;
4. les tarifs Premium réellement commercialisés ;
5. le médiateur de la consommation compétent et ses coordonnées, lorsqu'il est applicable ;
6. les modalités exactes de résiliation et de rétractation du parcours de souscription ;
7. les conditions spécifiques des Ateliers au moment de leur ouverture à la vente.
